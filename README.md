#  EcoENERGYHome21

EcoENERGYHome21 is an academic data science and development project focused on analyzing, predicting, and optimizing residential energy consumption.

##  Project Objectives
- Analyze household energy consumption data
- Build predictive models for energy usage
- Provide dashboards and intelligent insights
- Support decision-making for energy optimization

##  Main Features
- Data preprocessing and analysis (Python, Pandas)
- Machine Learning models for prediction
- Interactive visualizations
- Alerts and notifications system
- Modular architecture

##  Technologies Used
- Python
- Pandas, NumPy, Scikit-learn
- Jupyter Notebook
- Streamlit
- SQLite
- Power BI (external dashboards)

##  Project Structure
EcoENERGYHome21/
│── data/

│── pages/
│── database/
│── reports/

##  Project Context
This project was developed as part of an academic engineering curriculum in Data Science.
